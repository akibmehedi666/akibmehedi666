My work focuses on building reliable retrieval-augmented generation (RAG) pipelines, low-latency edge computer vision models, and mathematically optimized web applications.

### Focus Areas

- **Generative AI & LLM Safety:** Retrieval-Augmented Generation (RAG), vector similarity search, and classical ML hallucination verification for low-resource languages.

### Featured Projects

#### [Bengali Drug-Safety RAG & Hallucination Detection](https://github.com/akibmehedi666/bn-drug-safety-rag)
A clinical safety verification system for maternal healthcare in Bengali. Combines 384-dimensional multilingual sentence embeddings (`MiniLM-L12-v2`) and hybrid vector search across 302 drug monographs with a classical machine learning classifier (Logistic Regression & Random Forest) to verify faithfulness and detect LLM hallucinations.  
`Python` • `PyTorch` • `SentenceTransformers` • `Scikit-learn` • `Gemini API`

#### [Invincible Rock-Paper-Scissors (Sub-0.6ms CPU Inference)](https://github.com/akibmehedi666/RPS-Semi-Arm)
A real-time computer vision system that predicts hand gestures from standard laptop webcam streams. Adapts neuromorphic event camera concepts using consecutive frame differencing and binary thresholding, paired with `RoshamboNet v2`—a custom 115K-parameter PyTorch CNN achieving 93.92% validation accuracy with ~0.60ms CPU inference.  
`Python` • `PyTorch` • `OpenCV` • `NumPy` • `Edge AI`

#### [CompeteX](https://github.com/akibmehedi666/CompeteX)
An interactive web portal for university competitions and tech hackathons. Features Leaflet geospatial campus venue mapping, dynamic contest leaderboards, automated team formation matchmaking, and 1-on-1 mentorship booking.  
`Next.js 16` • `React 19` • `TypeScript` • `Leaflet` • `Tailwind CSS`

#### [OPERATION: ME](https://github.com/akibmehedi666/OPERATION-ME)
A tactical mission control, academic planner, and competitive programming tracker. Built with Next.js 14 App Router, Supabase PostgreSQL with Row Level Security (RLS), and an offline-first localStorage engine, backed by an automated testing pyramid featuring Vitest unit tests and Playwright end-to-end specifications.  
`Next.js 14` • `TypeScript` • `Supabase (PostgreSQL & Auth)` • `Playwright` • `Vitest`

#### [Eureka!](https://github.com/akibmehedi666/Eureka)
A collaborative academic research paper library and literature review notebook. Features automated arXiv and DOI metadata extraction with WAF fallback handling, Supabase Storage for PDF ingestion, and structured margin notes panels.  
`Next.js 15` • `React 19` • `TypeScript` • `Prisma ORM` • `Supabase`

#### [UIU Routine Builder](https://github.com/akibmehedi666/uiu-routine-builder)
A high-performance academic schedule generator for university students. Executes a 64-bit bitmask backtracking search algorithm inside a dedicated background Web Worker to explore thousands of section combinations in milliseconds at 60 FPS without UI blocking, ranked by a multi-criteria scoring engine.  
`Next.js 14` • `TypeScript` • `Web Workers` • `Tailwind CSS` • `Vitest`

#### [Echoes Without Words (Team-Karasuno)](https://github.com/akibmehedi666/Team-Karasuno)
An abstract, interactive generative art and ambient audio experience. Implements a 500-particle Perlin noise flow field rendered at 60 FPS on HTML5 Canvas synchronized with dynamic Web Audio synthesis and harmonic presets powered by Tone.js.  
`Next.js 16` • `React 19` • `p5.js` • `Tone.js` • `Tailwind CSS`
